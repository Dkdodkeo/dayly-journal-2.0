# Daily Journal
https://dkdodkeo.github.io/dayly-journal-2.0/
A clean, minimalist daily planner inspired by the iOS design language. Plan your day, check off tasks as you go, and keep everything in one simple place.

## Features

- Add tasks in seconds with a single input field
- Mark tasks as done with a tap and see them crossed out
- Delete tasks with a swipe on mobile or a button on desktop
- Browse between days to plan ahead or review the past
- Progress bar showing how much of the day is completed
- Clear all completed tasks with one click
- Automatic light and dark theme
- Fully responsive layout for phones, tablets, and desktops
- Tasks are saved in the browser, so nothing is lost after a refresh

## Built With

HTML, CSS, and vanilla JavaScript. No frameworks, no dependencies.
